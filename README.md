# 📚 Bookstore App (MERN)

Простое CRUD-приложение на MERN-стеке для управления книгами.

## 🔧 Возможности

### Backend (Node.js + Express + MongoDB)
- CRUD API для книг
- Express Router (`/api/books`)
- MongoDB (через Mongoose)
- CORS настроен

### Frontend (React)
- CRUD-интерфейс для книг
- React Router для навигации
- Axios для запросов к серверу
